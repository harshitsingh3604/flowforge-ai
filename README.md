# FlowForge AI

FlowForge AI is a secure AI workflow orchestration platform that lets users build and run workflows by connecting AI models, API requests, conditions, and approval steps in a single workflow.

The project is being built with a modern React-based frontend and a GraphQL-powered backend using Nhost, Hasura, and PostgreSQL.

## Status

**Under active development**

The core workflow engine and application features are currently being implemented.
